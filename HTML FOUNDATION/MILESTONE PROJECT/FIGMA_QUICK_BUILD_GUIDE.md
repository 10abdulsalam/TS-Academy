# 🎨 FIGMA DESIGN - QUICK BUILD GUIDE
## Milestone Project - Step by Step

### ⚡ Quick Setup (1 minute)

**File Name:** Milestone Project Design  
**Frame Type:** Desktop (1440 × 3200px)

#### Step 1: Rename the File
- Click **"Untitled"** at top
- Type: `Milestone Project Design`
- Press Enter

#### Step 2: Create First Frame
- Left panel → Click **"+" next to "Assets"** → Select **Desktop**
- Set dimensions: **Width: 1440px, Height: 3200px**
- Name it: **"Main Page"**

---

## 🏗️ BUILDING THE DESIGN (Follow in Order)

### SECTION 1️⃣: HEADER (0 - 280px)

**Step 1: Create Header Rectangle**
```
1. Click Rectangle tool (or press R)
2. Draw rectangle on frame → Position top
3. Width: 1440px, Height: 280px
4. Position: X=0, Y=0
5. Fill: Gradient
   - Stop 1: #667eea (left)
   - Stop 2: #764ba2 (right)
   - Angle: 135°
```

**Step 2: Add Logo (Emoji)**
```
1. Click Text tool (or press T)
2. Click on header rectangle
3. Type: 🌐
4. Font size: 60px
5. Color: White
6. Center horizontally
7. Y position: 50px
```

**Step 3: Add Main Heading**
```
1. Text tool → Click below emoji
2. Type: Welcome to Our Platform
3. Font size: 32px
4. Font weight: Bold
5. Color: White
6. Center align
7. Y position: 120px
```

**Step 4: Add Subheading**
```
1. Text tool → Click below heading
2. Type: Discover Amazing Content and Services
3. Font size: 16px
4. Color: White (Opacity: 90%)
5. Center align
6. Y position: 160px
```
